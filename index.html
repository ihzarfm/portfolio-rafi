Research & development

Centralized Firewall for Server Infrastructure

An OPNsense-based virtual security appliance for centralized access control to the servers I manage.

Virtual security appliance berbasis OPNsense untuk kontrol akses terpusat ke server yang saya kelola.

ProblemMasalah
Firewall control is scattered: native Linux firewalls on each server, plus rules on the routers.
Kontrol firewall masih tersebar: native Linux firewall di tiap server dan rules di router.
GoalTujuan
OPNsense as the security gateway between the transit network and server subnets, for a standard firewall policy, segmentation and admin access control.
OPNsense jadi security gateway antara transit network dan server subnet, untuk standardisasi firewall, segmentasi, dan kontrol akses administratif.
Progress & next stepsProgress & next step
ContributionKontribusi
Deployed OPNsense on Proxmox, worked through rule design and traffic flow, and tested integration with MikroTik routing and WireGuard.
Deploy OPNsense di Proxmox, pelajari rule design dan traffic flow, lalu uji integrasinya dengan routing MikroTik dan WireGuard.
Progress
Admin access and routing work in the test environment. Rule evaluation and documentation are ongoing.
Akses administratif dan routing di lingkungan uji sudah jalan. Evaluasi rule dan dokumentasi masih berlangsung.
Next
Firewall policy baseline, protected-service mapping, access rule testing and a rollback procedure before going to production.
Firewall policy baseline, pemetaan protected service, testing access rule, dan rollback procedure sebelum masuk production.
